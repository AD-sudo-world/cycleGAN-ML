# CycleGAN для генерации архитектурных схем фасадов

Реализация модели **CycleGAN** (Cycle-Consistent Generative Adversarial Network) для задачи image-to-image перевода: преобразование фотографий фасадов зданий в архитектурные схемы и обратно, **без необходимости в парных обучающих данных**.

Проект основан на наборе данных [CMP Facade Database](http://cmp.felk.cvut.cz/~tylecr1/facade/).

---

### 📖 Описание проекта

CycleGAN — это архитектура генеративно-состязательных сетей, которая позволяет обучаться на **непарных** данных. Это значит, что для обучения не требуется, чтобы каждому изображению фасада соответствовала его точная схема.

Модель изучает два маппинга:
- **G_AB**: Фасад → Схема
- **G_BA**: Схема → Фасад

Ключевая идея — **Cycle Consistency Loss**, которая гарантирует, что `G_BA(G_AB(A)) ≈ A`, что позволяет сохранять смысловое содержимое изображения.

---

### ✨ Возможности
- Генерация архитектурных схем из фотографий фасадов.
- Создание реалистичных фасадов из чертежей.
- Обучение без парных данных.
- Сохранение весов моделей и примеров генерации в процессе обучения.
- Использование Replay Buffer для стабилизации обучения дискриминатора.

---
**Основные этапы в `facades.ipynb`:**

1. **Импорт библиотек** — torch, torchvision, numpy, PIL, matplotlib и др.
2. **Подготовка данных** — распаковка архива, разделение на `facades/` и `schemes/`.
3. **Классы и функции:**
   - `ReplayBuffer` — буфер для хранения сгенерированных изображений.
   - `LambdaLR` — планировщик learning rate.
   - `PairedFacadesDataset` — загрузчик данных PyTorch.
   - `weights_init_normal` — инициализация весов.
   - `ResidualBlock` — остаточный блок генератора.
   - `GeneratorResNet` — архитектура генератора.
   - `Discriminator` — архитектура дискриминатора (PatchGAN).
4. **Настройка обучения** — оптимизаторы, функции потерь, DataLoader.
5. **Цикл обучения** — обучение генераторов и дискриминаторов.
6. **Сохранение результатов** — веса моделей и примеры изображений.
---
### 📊 Результаты

После обучения **10 эпох** модель успешно справляется с обеими задачами:
- **Фасад → Схема:** генерирует архитектурный чертёж по фотографии.
- **Схема → Фасад:** создаёт реалистичное изображение здания по чертежу.
